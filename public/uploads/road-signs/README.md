# Ontario road sign images

These SVGs are original drivexam study-card recreations, not copied from Ontario.ca or third-party image files.

Reference used for labels and meanings: https://www.ontario.ca/document/official-mto-drivers-handbook/signs

The artwork uses simple geometric road-sign conventions so the app can teach Ontario handbook meanings while avoiding copied MTO raster images or previously mislabelled Commons files.

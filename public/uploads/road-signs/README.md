# Ontario road sign images

Road-sign assets are sourced from Louie's `ontario-road-signs` folder.

Source of truth:

- `ontario-road-signs/ontario_road_signs.json` defines each sign name, category, description, and filename.
- `ontario-road-signs/icons/*.png` contains clean sign-only image files.
- Public runtime copies live under `public/uploads/road-signs/ontario-road-signs/`.
- The app stores sign name in `title` and answer explanation text in `description`; the PNG images stay sign-only.
